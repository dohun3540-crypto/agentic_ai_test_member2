# Reliability comparison results

Generated with `python run_reliability_comparison.py` using 100 tasks × 10 runs per condition and seeds 42–51.

The official integrated result files under `results/` are not overwritten. This directory is isolated for Member 2 Reliability experiments.

## Conditions

- Cumulative
- Sliding Window: 5, 10, 20
- EWMA: alpha 0.1, 0.3, 0.5
- Baseline reference: existing BaselineRouter

## Important metric rule

`detection_lag` and `recovery_lag` can be null. The mean lag is therefore reported **only among successful runs** and must be read together with:

- `valid_detection_runs`
- `detection_success_rate`
- `valid_recovery_runs`
- `recovery_success_rate`

For example, Sliding Window 10 has recovery lag 15.0, but recovery was observed in only 1/10 runs, so 15.0 is not a 10-run average.
